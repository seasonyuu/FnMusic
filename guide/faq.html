还有些问题？

这里整理了开始使用时最常遇到的疑问。应用仍在开发中，功能与界面可能变化。

FnMusic 是飞牛官方应用吗？

不是。FnMusic 是独立开发的非官方第三方 Android 客户端，与飞牛官方无关联，也没有使用官方公开 API。它根据当前飞牛音乐 Web 客户端的行为实现连接。

需要什么 Android 和 fnOS 版本？

Android 最低要求是 8.0。由于连接依赖观察到的 Web 客户端行为，不同 fnOS 版本的兼容性可能有所差异；目前不承诺一份完整的 fnOS 版本兼容清单。

能直接在这里下载 APK 吗？

下载按钮会打开项目的最新 GitHub Release。在那里下载 app-release.apk，也可以取得 SHA-256 校验文件。本站不提供额外的 APK 镜像。

在线歌词会上传我的 NAS 凭据吗？

不会。在线歌词搜索会把歌曲名和歌手名发送给所选歌词来源；NAS 凭据不会发给这些来源。登录和连接配置保存在设备本地的加密存储中。

AirPlay 能在所有接收器上使用吗？

目前不能作此承诺。实际听音和控制已在 macOS 接收端验证；HomePod、Apple TV、多房间及其他接收器类型尚未确认。AirPlay 仍属于实验性功能。

应用会自动安装更新吗？

不会。“关于”页面可以手动检查稳定版更新，查看简短说明并打开对应 GitHub Release。应用本身不会下载或安装 APK。

遇到问题怎么反馈？

请先查看相关指南，再到 GitHub Issues 描述设备、Android 与 fnOS 版本，以及复现步骤。不要在公开问题中提供密码、Cookie、Token 或完整私人服务器地址。
