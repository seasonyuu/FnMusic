FnMusic/使用指南/开始使用

先连接自己的音乐。

FnMusic 面向 Android 8.0 及以上设备。安装应用后，用已有的飞牛音乐服务账号连接你的 NAS。

下载安装

  1. 打开 最新 GitHub Release，下载 app-release.apk。发布页同时提供 SHA-256 校验文件。
  2. 在 Android 设备上打开 APK，并按系统提示允许本次安装。若已安装旧版，请直接更新，保留原有应用数据。
  3. 启动 FnMusic，进入连接页面。首次使用前，请确认 NAS 上的飞牛音乐服务已经可用。

下载来源：本网站只链接到 GitHub Release，不托管或重新打包 APK。请核对发布仓库为 seasonyuu/FnMusic。

连接 NAS

你可以使用 FN Connect 查找和连接自己的设备，也可以输入自定义 NAS 地址。使用已有的音乐服务账号登录；FnMusic 不提供 NAS 账号注册。

自定义地址优先使用 HTTPS。若填写局域网内的普通 HTTP 地址，应用会要求你明确确认。连接成功后，首页和音乐库会开始读取该账号可访问的内容。

下次打开时

应用会检查已保存的会话；会话过期时会尝试重新登录。退出登录会结束当前会话，但保留连接表单。登录信息与连接配置保存在设备本地的加密存储中。

从源码构建

如果更习惯自行构建，请参阅仓库的 构建说明。构建前需要 Android SDK、JDK 及项目子模块。
